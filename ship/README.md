# ship — 사진편집 프로그램 자동 배달

사진편집 프로그램(PhotoGrader 웹 프로그램, 판매용 코드)의 수정분을 **잠가서** 올려 두는 곳이다. 프로그램 코드를 그대로 두는 곳이 아니다.

- `album.pub.json` — 노트북의 잠그는 열쇠(공개해도 되는 쪽). 푸는 열쇠는 노트북의 `data/ship_key.json`에만 있다.
- `album.bin` — 잠근 묶음(프로그램 파일 zip). 노트북만 풀 수 있다.
- `album.json` — 묶음 안내문(내용 지문, 열쇠 이름, 한 줄 설명).

노트북의 우석World 서버가 5분마다 저장소를 확인하다가 새 묶음이 보이면 풀어서 프로그램의 자체 업데이트 기능(zip 올리기)에 넣는다.
사진·사진 DB·설정·API 키는 묶음에 없다.
